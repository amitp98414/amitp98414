Contributing
=============

Thanks for your interest in contributing! To keep contributions fast and clear, please follow these guidelines:

- Fork the repository and create a feature branch: `git checkout -b my-feature`
- Keep changes small and focused; open one PR per logical change
- Run tests locally (if applicable) and ensure linting passes
- Write clear PR descriptions and reference relevant issues
- Use conventional commit messages when possible

Maintainers will review PRs and request changes where needed. For larger proposals, open an issue first to discuss design.
